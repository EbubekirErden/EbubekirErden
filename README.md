# Ebubekir Erden

Computer Engineering student at Boğaziçi University, interested in AI/data systems, full-stack development, and infrastructure for intelligent applications.

## Working Areas

### AI, Data Mining, and NLP
I work on data processing problems involving unstructured text, news/event data, recommendation systems, semantic similarity, clustering, and lightweight NLP/ML models.

Tools and topics I have worked with include PyTorch, BERT-based models, spaCy, sentence embeddings, recommendation-system architectures, and OSINT-oriented data pipelines.

### Full-Stack and Mobile Development
I build web and mobile applications with production-style workflows, including frontend interfaces, backend API integration, testing, pull requests, and documentation.

My recent work includes React/TypeScript web development, Expo/React Native mobile development, Django REST APIs, and PostgreSQL-backed applications.

### Systems and AI Infrastructure
I am interested in how AI systems are deployed, tested, and scaled. I have worked on containerization, orchestration, benchmarking, Linux-based environments, and distributed architecture experiments.

Technologies I have used include Docker, Podman, Kubernetes, K3s, HashiCorp Nomad, Linux/Unix systems, and basic internal tooling for testing and comparison.

### Algorithms, Simulation, and Game Systems
I enjoy projects where correctness and state management matter: data structures, graph algorithms, deterministic simulations, game engines, bots, and rule-based systems.

Some of my public projects explore real-time multiplayer systems, deterministic bots, simulation-based testing, and structured game-state logic.
